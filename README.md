# JB Tech Consultants Website

## Run locally

1. Open this folder in VS Code.
2. Open the terminal:
   npm install
   npm run dev
3. Visit http://localhost:3000

## Google Maps

This version does **not** use Google Places API, Google Maps API, or any API key.

The location buttons use the direct Google Maps listing link:

https://maps.app.goo.gl/EpYLHGk3XWV8uBSZ7?g_st=ac

## Gallery

The gallery uses the 11 supplied local business images from `public/images/`:

- jb-tech-01.jpg through jb-tech-11.jpg

No Google Maps image scraping or API photo fetching is used.
